# Metodologia e Neutralidade - Eleitor Consciente 2026

## 1. Princípios Norteadores

O projeto foi construído para servir como instrumento cidadão de consulta e organização pessoal. Os quatro pilares fundamentais são:

1. **Neutralidade Estrita:** Nenhuma funcionalidade da plataforma sugere, recomenda ou desaconselha voto em qualquer candidato ou legenda.
2. **Ausência de Rankings:** O sistema não estabelece notas automáticas de qualidade, honestidade, idoneidade ou prioridade para nenhum postulante a cargo público.
3. **Auditabilidade Total:** Qualquer cidadão ou pesquisador pode auditar o código-fonte e verificar os relatórios de execução de cada importação realizada.
4. **Isenção Comercial:** Não há venda de destaque, anúncio ou publicidade paga na plataforma.

---

## 2. Processo de Tratamento de Dados

- **Coleta Automatizada:** Os dados são obtidos via adaptadores programáticos que leem os conjuntos do Portal de Dados Abertos do TSE.
- **Normalização Sem Alteração de Sentido:** Apenas padronizações técnicas (remoção de caracteres de controle, conversão de encodings e mapeamento de códigos de cargos) são efetuadas.
- **Anotações do Eleitor:** Quaisquer ponderações ou análises sobre o candidato pertencem unicamente ao eleitor e são armazenadas estritamente de forma local no seu próprio navegador.
