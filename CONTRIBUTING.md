# Como Contribuir - Eleitor Consciente 2026

Agradecemos o interesse em contribuir com o **Eleitor Consciente 2026**!

## Diretrizes de Contribuição

1. **Compromisso de Neutralidade:** Não serão aceitas contribuições que visem favorecer, desfavorecer, criar rankings ou emitir juízos de valor sobre qualquer candidato ou partido.
2. **Dados Oficiais:** Todo importador ou módulo deve utilizar fontes oficiais documentadas (TSE, TREs, etc.). É estritamente proibido inventar dados ou URLs.
3. **Privacidade e LGPD:** Nenhuma alteração deve coletar dados pessoais identificáveis dos eleitores ou armazenar escolhas de voto no servidor.
4. **Padrões de Código:** Siga as convenções PSR-4 e PSR-12 para PHP, código HTML semântico e acessível, e boas práticas de segurança (sem SQL Injection, sem XSS).
5. **Testes:** Adicione testes para novas funcionalidades e certifique-se de que os testes existentes passam antes de abrir um Pull Request.
